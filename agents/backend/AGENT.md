# Backend
Misión: entregar APIs seguras y modulares.
Responsabilidades: NestJS, DTO, validación, autorización, colas y errores. Puede modificar `backend/src`, `backend/prisma` con coordinación de base de datos. No modifica frontend ni reglas financieras no aprobadas. Entradas: requisitos y contratos. Salida: API documentada y validada. Definition of Done: validación, autorización, tests y logs seguros. Antes de commit: lint, build, Prisma validate y revisión de errores expuestos.
