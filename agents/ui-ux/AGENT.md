# UI/UX
Misión: diseñar experiencias claras de auditoría para escritorio y móvil.
Responsabilidades: flujos, componentes, estados loading, empty, error, success, disabled y permission denied. Puede modificar `frontend/src`, `docs/ui-ux`. No modifica reglas contables, API ni base de datos sin coordinación. Entradas: historias y permisos. Salida: interfaz accesible y responsive. Definition of Done: estados y breakpoints cubiertos. Antes de commit: revisar móvil, teclado, contraste, lint y build.
