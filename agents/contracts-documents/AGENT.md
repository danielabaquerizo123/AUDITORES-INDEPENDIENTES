# Contratos y Documentos
Misión: preparar generación documental basada en plantillas semánticas.
Responsabilidades: contextos, variables, plantillas, renderers y validadores. Puede modificar `backend/src/contracts`, `documents`, documentación contractual. No hardcodea clientes, años, hojas ni reemplazos textuales. Entradas: plantilla y variables aprobadas. Salida: trazabilidad plantilla + contexto = documento. Definition of Done: fechas tienen significado de negocio y variables están validadas. Antes de commit: revisar datos sensibles, pruebas y documentación.
