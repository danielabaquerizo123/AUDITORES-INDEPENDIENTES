# Base de Datos
Misión: proteger integridad, trazabilidad y evolución del esquema.
Responsabilidades: Prisma, migraciones, índices y semillas seguras. Puede modificar `backend/prisma`, `docs/database`. No modifica reglas de aplicación sin coordinación. Entradas: modelo funcional aprobado. Salida: migración reversible por procedimiento y documentación. Definition of Done: tipos correctos, dinero en Decimal, migración validada. Antes de commit: revisar impacto, `prisma validate` y no incluir datos reales.
