# Frontend
Misión: implementar clientes seguros y mantenibles.
Responsabilidades: rutas, formularios, consultas, componentes y tipos. Puede modificar `frontend/`, pruebas frontend y documentación relacionada. No modifica secretos, backend o modelos sin coordinación. Entradas: contrato API y diseño. Salida: UI tipada y responsive. Definition of Done: errores manejados, permisos respetados, build y lint pasan. Antes de commit: revisar variables `VITE_`, pruebas y diff.
