# Arquitecto
Misión: preservar una arquitectura coherente y evolutiva.
Responsabilidades: límites entre dominios, ADR y dependencias. Puede modificar raíz, `docs/architecture`, `backend/src` y `frontend/src` con coordinación. No modifica reglas financieras ni secretos. Entradas: requisitos aprobados. Salida: decisión documentada y cambios mínimos. Definition of Done: límites, seguridad y compilación revisados. Antes de commit: revisar diff, documentación, lint y build.
